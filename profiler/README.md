# 琴音（kotone）声質プロファイル作成ツール

録音した自分の声（WAV）から、OBS の「琴音 (Kotone) 声質フィルタ」用のプロファイルを作るツールです。
先に OBS プラグイン本体（`kotone-windows-x64.zip`）を入れておいてください。

## 使い方（Windows）

1. **録音する**: マイクの素の声（OBS のフィルタを通さない音）を 30 秒〜3 分ほど話して WAV で保存します。普段の配信と同じ話し方・距離で、息継ぎが入っていても大丈夫です。
2. **ドラッグ＆ドロップ**: 保存した `.wav` を `analyze_voice.bat` の上にドラッグ＆ドロップします。
3. **名前とプリセットを選ぶ**: 黒い画面でプロファイル名を入力し（Enter だけならファイル名）、プリセットを番号で選びます。
   - `1` 普段の配信向け（標準）
   - `2` 囁き声・ASMR 向け（小さい声を守る控えめな処理）
   - `3` ゲーム配信向け（自然なフラット補正）
4. **OBS で選ぶ**: OBS の琴音フィルタで「プロファイル一覧を再スキャン」を押し、作ったプロファイルを選びます。

プロファイルは `%APPDATA%\obs-studio\plugin_config\kotone\profiles` に保存されます。
シーンごと（普段トーク・ゲーム・囁き声など）に録音して何個でも作れます。

Python は同梱しているのでインストール不要です（`python` フォルダは消さないでください）。

## うまくいかないとき

- `ERR_INSUFFICIENT_SPEECH`: 話している部分が 5 秒未満です。もう少し長く録音してください。
- `ERR_INVALID_WAV`: WAV 以外、または壊れたファイルです。16/24/32-bit PCM か 32-bit Float の WAV で保存してください。
